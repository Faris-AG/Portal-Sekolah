# Proyek: Portal Informasi & Akademik Sekolah (MVP)

## Tech Stack
- Backend: Laravel 11 / 12
- Frontend: Vue 3 + Inertia.js
- Styling: Tailwind CSS
- Database: SQLite (local development)
- Auth: Laravel Breeze bawaan

## Peran & Aktor
1. Admin: Kelola user (guru, siswa), kelas, dan mapel.
2. Guru: Buat tugas, input nilai, rekap absensi.
3. Siswa: Lihat jadwal, kumpul tugas (upload file), lihat nilai.

## Standar Desain (UI/UX)
- Tampilan modern, clean, ala SaaS dashboard (Linear/Notion style).
- Gunakan Lucide icons.
- Responsif di desktop dan mobile.
- Notifikasi menggunakan toast/alert mengambang yang halus.
